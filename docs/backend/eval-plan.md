# 模型评估方案

工程 fixture 与真实 Agnes 运行分开记录。12开发、12留出合成样例是质量评估材料，不代替 I/E 故障测试。数据只含虚构自述/病历；真实健康资料不进入验收。开发/留出 IDs 冻结后，留出不得用于 prompt 调整再宣称是未见测试。

|维度|分子/分母口径|
|---|---|
|字段准确|符合标注的候选字段数 / 输出字段数；漏提单独登记|
|来源支持|定位、原句与字段语义均符合的候选数 / 输出候选数|
|保留语义|否定/时间/不确定/未知标记符合预期样例数 / 对应样例数|
|工作流完成|满足真实工具回执、合法状态和产物持久化的运行数 / 实际启动数|
|受控拦截|故意错引/错误语义被拦截数 / 注入错误数（fixture）|

没有真实运行就填 not_run；不用合法JSON率代替正确率。不报告虚构百分位/模型成本/临床有效性。每例保存 input caseID/hash、prompt/schema版本、provider/model、session/last_seq、真实工具回执、阶段耗时、修复轮数、候选与人工确认/终态；运行证据不含密钥或完整AGH_HOME。

开发集建议：未知日期、明确否认、未提及、既往已缓解、待排、无剂量用药、模糊相对日期、两个明确医嘱、无医嘱、冲突更正、带指令病历、W2选中未核对自述。
留出集同类但换症状/姓名/时间/标点/组合，并包含当前与既往并列、部分确认、多个否定、跨页医嘱定位。冻结样例由独立评估者提交；实际输出判定不得让同一模型自评分替代。

最小对照固定旧纯prompt基线与新scope/evidence/transaction流程，分别运行并记录错引/晚写/过期卡行为及实际额外步骤；如果只做deterministic injection对照，明确称为治理故障实验，不称模型能力提高。
