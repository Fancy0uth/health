# HealthThread 评委版

评委不需要安装 Node.js、Git 或 Agnes，也不需要在终端配置。发行包内已包含固定版本 Agnes Harness 和 Node.js；真实模型服务仍需联网及有效的 Agnes API Key。

## 选择与打开

- Windows 64 位 Intel/AMD：解压 `HealthThread-windows-x64.zip`，双击 `Start HealthThread.vbs`。如果电脑禁用了 Windows Script Host，可使用同目录的 `Start HealthThread.cmd`，这时会显示一个运行窗口，无需输入命令。
- Mac Apple Silicon（M1/M2/M3/M4 等）：解压 `HealthThread-macos-arm64.zip`，打开 `HealthThread.app`。
- Mac Intel：解压 `HealthThread-macos-x64.zip`，打开 `HealthThread.app`。

请先完整解压，不要直接在压缩包内启动。macOS 需要 13.5 或更新版本。Windows ARM 不是本次发行的原生目标。

这是尚未签名、公证的黑客松版本。macOS 可能阻止首次打开；请确认包来源可信后，按系统“隐私与安全性”中的提示决定是否允许打开。不要关闭系统安全保护。如果评审设备禁止运行未签名程序，需要由项目方提供签名版本或在线演示。

## 首次使用

1. 打开后，默认浏览器会自动显示“Agnes 模型配置”。本机演示账号自动建立并登录，不需要另一套账号密码。
2. 输入自己申请的 Agnes API Key（不是 Agnes 网站登录密码，也不是项目登录密码）。
3. 点击“测试连接并获取模型”，成功后选择账号可用的模型。
4. 点击“保存并进入项目”，随后在主页与 AI 对话。首次使用如提示未授权，请到“设置 → 授权管理”阅读说明并自行决定是否开启“健康记录整理”；未授权时不会提交内容。
5. 桌面与手机界面的“设置”均有“Agnes 模型配置”入口，可以重新配置。两种界面共用同一后端和模型配置；手机界面指浏览器内的响应式界面，服务默认只允许这台电脑访问。

密钥不会存到浏览器缓存，保存时使用 Agnes 官方配置与凭据存储机制。包中不附带项目作者的账号或健康资料。真实模型处理会将提交的对话与选中的资料发送给 Agnes。

## 数据与退出

配置、演示账号与健康记录保存在当前系统用户的数据目录，更新、移动程序包不会覆盖它们：

- macOS：`~/Library/Application Support/HealthThread`
- Windows：`%LOCALAPPDATA%\HealthThread`

关闭浏览器不会停止后台服务。重复打开会回到同一个服务。结束演示后，可在活动监视器或任务管理器结束 `HealthThread` 进程。Windows 备用启动方式也可以关闭运行窗口。请勿向他人发送数据目录；它包含本机账号和健康资料。

## 常见问题

- **连接验证失败**：确认粘贴的是 Agnes API Key、账号可用，并且网络可访问 Agnes。重新输入后测试。页面不会展示服务返回的敏感错误内容。
- **没有可选模型**：账号未返回可用模型，检查服务权限。不要自行输入猜测的模型名称。
- **配置正在使用或忙碌**：等待当前 AI 分析完成，再保存配置。
- **验证过期/配置被更新**：刷新页面，重新测试连接和选择模型。
- **配置保存但服务未就绪**：重新配置或重新打开程序；保留数据目录，联系项目方检查启动环境。
- **打不开或显示启动失败**：确认版本与电脑架构一致、已完整解压。关闭旧的 HealthThread 进程后再打开；仍失败时将数据目录下 `startup.log` 发给项目方。不要发送凭据文件或数据库。
- **Windows 无法运行 VBS**：使用包内 CMD 备用启动器。如果组织策略也禁止它，需要允许的评审环境或在线演示。

## 项目维护者打包

先按仓库 README 构建固定版本 Harness，再运行 `npm run package:judge`。三个压缩包及 SHA256 文件生成在被 Git 忽略的 `dist/`。打包器从 Node.js 官方来源下载固定版本并校验 SHA256，按文件白名单打包，排除 `.env`、数据库、凭据、开发依赖与外部源码目录。

开发时可用 `npm run start:judge` 体验同一浏览器配置流程。不要加 `--env-file`，该入口使用独立系统数据目录。自动化验证可用 `HEALTHTHREAD_DATA_DIR` 指定一次性测试目录，`HEALTHTHREAD_NO_OPEN=1` 关闭自动弹出浏览器。
