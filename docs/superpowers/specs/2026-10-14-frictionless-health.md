# Frictionless patient records and body overview

User-directed revision, 2026-10-14. Ordinary patient conversation must unobtrusively produce editable records, without sentence-by-sentence approval. Meaningful new health details update a structured recent body-region overview automatically. Health overview is a synthesis, not a list of all factual statements. Unknown regions must not be asserted healthy. Information keeps immutable original sources and distinguishes patient report, medical-document statements and model suggestions.

Medical documents accept image or text. Images are genuinely transcribed by the configured Agnes model before a separate interpretation step. Complete transcription is retained; unclear text is marked rather than invented. Analysis uses related prior records to produce physician-instruction explanations, precautions and recovery guidance, distinctly labeling original instructions versus model suggestions. This also updates the health overview. Only real contradictions or uncertain recognition require grouped user review. Failed analysis preserves original uploads and offers retry. Existing privacy, user isolation, cancellation, idempotency, source validation and real-runtime verification remain intact. Doctor-card generation remains conversationally confirmed.

Both desktop and mobile use consistent button dimensions, semantic colors, icon boxes, spacing, status badges and responsive layouts. Status metadata must not masquerade as actions. Records should be editable as a whole with clear save and undo/error behavior, not force every extracted sentence through confirmation. Existing historical records remain accessible.

Acceptance includes genuine Agnes calls and browser interaction on both desktop and mobile: conversation → automatic record → body overview; whole-record edit; text medical document and synthetic image → transcription → contextual post-visit tasks → overview; actual conflict grouping; persistence on reload; all main navigation, drawers and form/action states checked for sizing, alignment and color.
